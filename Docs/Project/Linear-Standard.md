# SoNexus Linear Engineering Standard

## Purpose

This document records the verified Linear workflow facts for SoNexus.

Linear is the active engineering workflow and working-state management system. GitHub remains the Source of Truth for approved architecture, code and documentation.

## Workspace and Project

- Linear team: `SoNexus-Team`
- Production project: `SoNexus`
- Issue prefix: `SON`

## Statuses

The available issue statuses are:

- Backlog
- Todo
- In Progress
- In Review
- Done
- Canceled

## Workflow Boundary

Linear tracks engineering work and its current state. GitHub stores approved results.

Certification and test artifacts currently present in Linear are not part of the production workflow and will be cleaned separately.

## Scope

This standard intentionally records only verified Linear facts. It does not define unverified labels, templates, automation, lifecycle rules or API integrations.
