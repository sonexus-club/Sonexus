# PROJECT_RULES.md

> SoNexus Project Rules

---

# General Rules

- One chat = one project stage.
- Start a new chat only after the current stage is fully completed.
- No implementation before approval.
- Approved decisions become the project standard.
- GitHub is updated only after approval.

---

# AI Rules

- AI_CONTEXT.md is the primary AI context.
- AI documents are updated after every completed stage.
- The latest AI documents must be uploaded to the ChatGPT File Library.
- Every new project stage begins by loading AI_CONTEXT.md from the ChatGPT File Library.

---

# Documentation Rules

- English is the primary documentation language.
- Russian duplicates are allowed for long documents.
- Documentation follows Documentation First Development.

---

# Repository Rules

- GitHub is the official project repository.
- Repository structure changes require approval.
- Documentation changes require approval.

---

# ADR Rules

- One ADR = one architectural decision.
- ADR must be approved before implementation.

---

# Naming Rules

Always use:

SoNexus

Never use:

Sonexus

SONEXUS

---

# Development Philosophy

- Keep It Simple.
- Modular architecture.
- Incremental development.
- Test before expansion.
- Documentation before implementation.
